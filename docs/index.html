Privacy Policy

App: Gallery • Package: com.kaifazad.gallery • Developer: Kaif Azad • Updated: October 2026

1. Overview & Commitment

Gallery is built from the ground up with a strict privacy-first foundation. We believe that your personal photos, videos, and private moments belong solely to you.

Summary: Gallery operates completely on your local device. We do not collect, monitor, store, transmit, or share your personal data, photos, videos, or device telemetry with any party.

2. Zero Network Access (100% Offline)

The application has no internet access. The following Android permissions are explicitly stripped from the application manifest:

  • android.permission.INTERNET — Removed
  • android.permission.ACCESS_NETWORK_STATE — Removed
  • android.permission.ACCESS_WIFI_STATE — Removed

Because the application lacks network capabilities, it is technically impossible for the app to send your photos, videos, or metadata to external servers or cloud services.

3. Data Collection & Analytics

  • Personal Information: Zero personal information (names, emails, contacts, phone numbers, or accounts) is collected.
  • Media Files: All indexing, thumbnail rendering, and playback occur entirely on-device via Android's local MediaStore.
  • Analytics & Tracking: Gallery contains no trackers, no analytics SDKs, and no telemetry (no Google Analytics, Firebase, or third-party loggers).
  • Advertisements: The application contains no ads.

4. Permissions & On-Device Usage

The app requests only standard Android permissions necessary for local media playback:

Permission Usage Description
READ_MEDIA_IMAGES
READ_MEDIA_VIDEO		 Required on Android 13+ to display and organize your local media library via scoped storage.
ACCESS_MEDIA_LOCATION Enables viewing EXIF geographic coordinates (latitude & longitude) locally in the info viewer. Data never leaves the device.
MANAGE_MEDIA Optional permission on Android 12+ allowing seamless deletion and trashing without repetitive system dialogs.
POST_NOTIFICATIONS Displays on-device progress notifications during background encryption operations (Vault).
VIBRATE Provides tactile haptic feedback for user interactions.

5. Encrypted Vault Security

Gallery includes an on-device Vault for locking private photos and videos:

  • Encrypted at rest using industry-standard AES-256 GCM encryption.
  • Encryption keys are protected locally using the Android Keystore or user-defined credentials.
  • Encrypted files are hidden from system indexing, external apps, and scanners.

6. Third-Party Interactions

When you choose to share a media item or edit an image externally, Gallery delegates to standard Android system intent handlers. The chosen external application receives the file URI solely for that specific action.

7. Children's Privacy (COPPA Compliance)

Gallery does not collect or solicit any data from users of any age, including children under 13.
